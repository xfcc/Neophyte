# xfcc 的投资实证 · Neophyte

两只基金的名字不同，背后可能持有同一批公司。一只股票跌了不少，对整个账户的影响却可能很小。我做 Neophyte，是想在看涨跌之前，先弄清自己的钱投到了哪里。这里公开记录我的实际仓位，也留下每个时期给自己定的目标，方便日后对照。

## 资产配置

我愿意长期持有股票，因为持有股票让我有机会分享企业经营的成果。这份耐心取决于一件事。生活需要用钱时，我手里得有余地。自 **2026 年 11 月 17 日**起，我给这个账户定了以下目标。

| 资产 | 目标占比 | 在我的组合里承担什么 |
| --- | ---: | --- |
| 股票 | 60% | 参与企业的长期增长，也承担股价起伏 |
| 债券 | 20% | 获取利息收入，平衡股票带来的波动 |
| 现金 | 15% | 应对用钱需求，给后续配置留出余地 |
| 黄金 | 5% | 分散组合对股票和债券的依赖 |

我先看全账户仓位图，再看股票基金、个股、债券和投顾各自的变化。即使一笔交易都没做，股票上涨也可能把股票占比推高。把实际仓位和目标放在一起，我可以先查清偏离来自行情还是资金进出，再考虑是否需要再平衡。每次修改目标，都从生效日开始记录，过去的决定仍用当时的目标衡量。

## 持仓实盘

我把宽基指数当作选择股票投资的起点。持有一个行业或一家公司的理由，需要比“它最近涨得好”更具体。实盘把宽基、红利、主题和个股分开看，我会用同一行里的几组数字检查自己的判断。

- **持仓占比、分类占比**分别以全账户和当前细分类为分母。一只基金可以占某个主题的一半，却只占全账户的很小一部分。两列一起看，才知道我把多大一部分资产放在了这个判断上。
- **5 日波动、30 日波动**记录对应期间的累计涨跌。「波动率」把这次 5 日涨跌放回产品自己的历史中比较。例如，处于历史第 88 百分位时显示 +76%，说明这次表现靠近历史较强的一端。判断一家公司经营得怎样，还要看价格以外的证据。
- **温度**帮我把对资产的看法和对价格的判断分开。即使看好一个行业，我也想知道今天的估值放在历史里处于什么位置。部分产品采用对应指数的温度，黄金单列近十年价格分位。缺少合适参照或数据时，页面显示「—」。
- **持仓盈亏**记录相对我个人成本的回报，公开页默认遮挡。买入成本能解释这笔投资给我带来了什么。重新审视一笔持仓时，我更关心当初的理由今天是否还成立。

这套记录受有知有行《投资第一课》和孟岩《投资中，我相信的事》启发。如果你也想记录自己的投资，可以先写下每笔钱什么时候可能要用、每类资产为什么值得持有。目标比例可以和我的完全不同。等市场大幅波动时，回头还能读到自己在平静时做判断的理由，这份记录就有用。
