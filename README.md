# xfcc 的投资实证

这不是模拟组合，也不是某个时点的持仓截图。它持续记录我的真实投资组合：持仓比例如何变化，各类资产带来了怎样的收益，某一天或某一周的波动究竟普通还是少见。

我把它称为“投资实证”，是因为这里先留下事实，再讨论解释。市场每天都会制造新的价格，但真正值得进入判断的变化并没有那么多。连续记录可以减少记忆偏差，也让投资框架是否有效、实际配置是否偏离目标，最终有据可查。

## 查看投资实证

公开页面分成三个视角：

- **每日更新**：查看最近交易日的涨跌幅、产品波动和市场共振。
- **近 5 日更新**：把单日噪声放进一周尺度，观察累计变化是否进入产品自身的少见区间。
- **全局概览**：按比例查看长钱账户、独立股票基金、独立债券基金和主动个股，比较实际配置与目标配置，并观察各区域的持仓收益。

页面只展示百分比，不公开资产金额、持仓数量、成本、价格或账户信息。`—` 代表数据缺失或暂时无法计算，不使用临近日期或估算值补齐。

## 我的投资哲学

**比例比金额更重要。** 投资规模会随着持续投入和市场变化而增长，因此我不为组合设定一个静止的总金额。我更关心每类资产应该承担什么作用，目标比例与实际比例之间发生了什么变化。

**先配置，再选择。** 长钱账户、股票基金、债券基金和主动个股承担不同任务。单个产品的得失要放回组合里理解，不能只看它是否赚钱，也不能让一个短期赢家无意中改变整个组合的风险结构。

**波动首先是事实，不是指令。** 一次上涨或下跌不会自动导出买卖结论。这里先用产品自身的历史分位判断波动是否少见，再与主要参考基准和宽市场比较，区分产品特有变化与市场共同变化。

**交易应该低频，而且有明确缘由。** 对主动个股，我更关心从今天开始继续持有 A，是否仍然优于持有 B，而不是执着于买入成本、是否回本或某个机械止盈点。没有足够明显的新信息或更好的替代品，不交易本身也是一种选择。

**允许数据不完整，不允许把未知写成已知。** 公开市场数据统一通过项目锁定版本的 AkShare 接口采集，并保留实际市场日期。缺失会被直接标出，投顾账户的内部基金只用于穿透观察，不会与一级账户重复计算。

这个项目是一份个人投资记录，不构成投资建议，也不根据短期波动自动给出交易动作。
