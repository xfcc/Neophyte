# xfcc 的投资实证 · Neophyte

我用 Neophyte 记录自己的投资组合，定期回看实际仓位有没有偏离目标，以及市场涨跌怎样改变了组合。把这些变化连续记下来，几年后才能回看自己当时持有什么、依据什么调整，以及执行结果和原来的想法差了多少。我把这套框架和实盘记录放在一起，希望正在搭建自己投资框架的人也能借鉴这套记录和复盘方法。

[查看资产配置](https://neophyte-xfcc.vercel.app/#allocation) · [查看持仓实盘](https://neophyte-xfcc.vercel.app/#holdings)

## 我的投资框架

**先确定各类资产在组合里的作用。** 股票承担长期增长，也带来组合里主要的波动。债券用来平衡这部分波动，现金留给流动性需要和后续配置，黄金提供一部分分散。选具体产品时，我先看它能否承担对应的作用，再看已有持仓里是否有相似敞口。

自 **2026 年 11 月 17 日**起，我的全账户再平衡目标是：

| 资产 | 目标占比 |
| --- | ---: |
| 股票 | 60% |
| 债券 | 20% |
| 现金 | 15% |
| 黄金 | 5% |

**用实际仓位和目标的差距来复盘。** 市场涨跌和资金进出都会改变占比。我先看偏离来自哪里，再考虑这项偏离是否值得处理。历史仓位按各自日期的目标比较，目标每次调整都从生效日计入。

**把短期波动放回自己的历史里看。** 我用 5 日和 30 日累计涨跌了解近期变化，用产品自身的历史分位判断这次变动有多少见。温度提供估值在历史中的位置。对主动个股，我还会回到持有理由本身，看看出现了什么新信息，以及从今天出发是否仍愿意继续持有。

## 怎么看这份实盘

- **资产配置**展示全账户和各个子组合的仓位变化，并在设有目标的层级对照实际与目标。
- **持仓实盘**展示各产品的仓位占比、近期涨跌、波动、温度和持仓盈亏。公开数据以比例和统计指标呈现，缺项用「—」标出。

如果你想借鉴这套方法，可以给自己的组合留一份简单记录。写下每类资产的用途和目标比例，定期记实际占比，调整时记下日期和理由。这样过一段时间回看，既能看到市场怎么变，也能看到自己怎么做。
